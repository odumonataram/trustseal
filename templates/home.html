How TrustSeal Works

Three simple steps from registration to consumer verification.

📦

1. Register Product

Manufacturers log in and register each product with batch details. The system assigns a unique UUID and creates a database record.

📲

2. Generate QR Code

A QR code is automatically generated encoding the product's unique verification URL. Download it and print it on packaging.

✅

3. Consumer Verify

Consumers scan the QR code with their phone camera. The system checks the database and displays the product's authenticity status.

🛡️ How Counterfeits Are Detected

The three-layer protection model used by TrustSeal

🔑 UUID Uniqueness

Every product gets a UUID4 — a 128-bit random identifier. The chance of two products sharing the same ID is astronomically small, making duplication virtually impossible.

📊 Scan-Count Heuristic

Every scan is logged. If a QR code is scanned more than {{ 3 }} times, it triggers a counterfeit warning — a genuine product is typically scanned once by the end consumer.

🗄️ Database Lookup

If a scanned product ID does not exist in the database at all, the system immediately flags the product as unregistered / counterfeit — no match means no legitimacy.
